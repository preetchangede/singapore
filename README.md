# Singapore, reconstructed

The whole of Singapore, about 730 km² of land plus its waters, rebuilt in 3D from open data and
rendered live in the browser. You can fly across the island, drop to street level, follow the river,
watch the anchorages light up at dusk and scrub through a day of sun, haze and cumulus.

* 149,000 buildings in Singapore, plus 270,000 across the water in Johor and the Riau Islands.
  Footprints come from OpenStreetMap; heights come from OSM tags or HDB records, or are estimated
  by a model trained on the buildings whose heights are known.
* 1.6 million individual trees, detected in a 1 m canopy-height map.
* Bare-earth terrain, coastline, reservoirs, roads, rail, parks and land use for the whole country,
  plus Johor and the Riau islands on the horizon.
* 350+ ships anchored in the real MPA anchorages. Traffic transits the Singapore Strait separation
  scheme and ferries run their actual routes.
* A physically based sky (Hillaire 2020) with the sun and moon placed for the real date and time
  in Singapore.

Everything is generated by the pipeline in [`pipeline/`](pipeline) and streamed by the
dependency-light WebGL2 client in [`web/`](web) (three.js + earcut, nothing else).

| Drag | Move across the city |
| Right-drag / Shift-drag | Turn and tilt |

Places can be deep-linked (`#marina-bay`, `#east-coast`, …).

## How it works

### World frame and streaming

All geometry is projected to SVY21 (EPSG:3414) and re-centred near Toa Payoh. The detailed domain
is a 65,536 m square split into 16 × 16 bundles of 4 km, each containing 4 × 4 tiles of 1 km.
Bundles are gzip files of int16 delta-coded footprints, lines and points (about 45 MB for the
whole country, plus about 5 MB of terrain, textures, labels and maritime data). The client fetches
bundles around the camera, decodes them with the native `DecompressionStream` in a pool of web
workers, and meshes them there: building extrusion with per-class roofs, ground polygons, road
ribbons, bridges, tree instances and traffic lanes. A coarse overview of every building is always
resident, so the skyline is complete from any distance.

Terrain is a CDLOD quadtree over two height maps: 32 m near, and 128 m far out to 131 km so the
Johor and Riau coasts sit on the horizon. Ground detail (land use, roads, paths, water edges) is
rasterised into a three-level clipmap that follows the camera.

### Buildings

About 27% of Singapore's footprints in OpenStreetMap carry a height or level count, and HDB's
property register gives storey counts for another 7% (public housing). The remaining 66% are
estimated by a LightGBM model trained on the ~115k buildings with known heights. Its features are
footprint geometry, URA Master Plan zoning and plot ratio, 3D-GloBFP estimates, and neighbourhood
statistics.
Under spatial block cross-validation it reaches a median relative error of 2.2% and a MAE of 3.3 m
(the type-default baseline has an RMSE of 22.6 m; the model's is 10.1 m). Facades are procedural per building class
(HDB slabs with corridor lighting, shophouses with five-foot ways, curtain-wall towers, …) and
light up at night with a level-of-detail scheme that keeps distant towers sparkling without
shimmering.

### Light and atmosphere

* Sky: Hillaire 2020 transmittance, multiple-scattering and sky-view LUTs. Rayleigh, Mie and ozone,
  plus a 350 m humid boundary-layer haze that thickens on mornings and evenings.
* Aerial perspective: a 32 × 64 × 32 LUT of in-scattered light along finite camera-to-point
  segments (azimuth relative to the sun × elevation × distance), recomputed only when the sun,
  the haze or the camera altitude changes. Distant objects pick up exactly the haze between them
  and the camera, so the effect stays continuous at the horizon, including at sunset.
* Sun and moon positions, moon phase and moonlight come from a low-precision ephemeris for the
  actual date. Artificial lights switch on at civil dusk.
* Cascaded shadow maps (3 cascades in one atlas, texel-snapped and cached while static) and
  raymarched volumetric cumulus with their own shadows on the ground.
* Planar reflections on the sea, the reservoirs and Marina Bay; GPU auto-exposure; AgX tone mapping;
  bloom; FXAA.

### A living city

Cars and buses drive on the left along lanes extracted from the road graph, with time-of-day flow
(rush hours and quiet nights). Ships at anchor lie head to the tidal stream and swing round
together when it turns, about every six hours. Transiting ships keep to their side of the
separation scheme with wakes behind them. Ferries leave HarbourFront and Tanah Merah for Batam and
Bintan, and bumboats cross from Changi Point to Pulau Ubin.

### Performance

Four quality tiers (low → ultra) are picked from the GPU and screen, then adjusted by a dynamic-resolution
governor that holds the frame rate. Meshing never happens on the main thread, and draw calls are
batched per tile and per instanced class.

## Running locally

```bash
cd web && npm install && npm run dev
```

The generated data is checked in under `web/public/data`, so the client runs without the pipeline.

To rebuild the data you need Python 3.11+ and the raw inputs listed below in `$SG_WORK/raw`
(default `/home/user/singapore-work/raw`):

```bash
python -m venv venv && . venv/bin/activate && pip install -r pipeline/requirements.txt
```

```bash
cd pipeline && python -m sgpipe.osm && python -m sgpipe.terrain && python -m sgpipe.heights && python -m sgpipe.vegetation && python -m sgpipe.features && python -m sgpipe.landmarks && python -m sgpipe.maritime && python -m sgpipe.bundles && python -m sgpipe.ground && python -m sgpipe.globals
```

### Static deployment

```bash
cd web && npx vite build && node scripts/build-artifact.mjs
```

`build-artifact.mjs` inlines the app into a single page fragment, copies the data next to it and
can rename binary files to an extension the host accepts (the manifest records the extension).
